# Scene di AFTER 10

Qui vanno le immagini cinematografiche delle scene, in formato **WebP**,
verticali (consigliato **1080×1920**, 9:16). Il nome del file deve essere
**esattamente** quello indicato: il gioco lo carica in automatico e, se il file
non c'è, ripiega sullo spioncino vettoriale (nessun errore).

I **prompt** pronti per generarle sono in `docs/scene-prompts.md`.

## File attesi (15 scene = 3 verità × 5 momenti)

| File | Momento |
|------|---------|
| `blk-1.webp` | Blackout — buio improvviso sul pianerottolo |
| `blk-2.webp` | Blackout — torcia che sale le scale |
| `blk-3.webp` | Blackout — torcia ferma alla porta di fronte |
| `blk-4.webp` | Blackout — torcia che si allontana in alto |
| `blk-5.webp` | Blackout — buio totale, silenzio |
| `int-1.webp` | Intrusione — pianerottolo vuoto, lampadina svitata |
| `int-2.webp` | Intrusione — ombra/guanto sul gradino |
| `int-3.webp` | Intrusione — sagoma di fianco allo spioncino |
| `int-4.webp` | Intrusione — colpi alla porta, zerbino spostato |
| `int-5.webp` | Intrusione — spioncino coperto, un occhio |
| `fls-1.webp` | Falso allarme — pianerottolo normale, quadro caduto |
| `fls-2.webp` | Falso allarme — corridoio tranquillo |
| `fls-3.webp` | Falso allarme — la vicina rientra con le buste |
| `fls-4.webp` | Falso allarme — pianerottolo deserto e illuminato |
| `fls-5.webp` | Falso allarme — interno tranquillo, luce di lampada |

Puoi iniziare con **3 immagini "hero"** (`blk-1`, `int-3`, `fls-1`) per vedere
subito l'effetto, e aggiungere le altre quando vuoi.

## Consiglio dimensioni
Comprimi le WebP a ~150–250 KB l'una (qualità 70–80): 15 scene restano sotto
i ~3 MB totali, ok per una PWA offline.
